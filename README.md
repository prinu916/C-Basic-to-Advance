# 🚀 C++ Basic to Advance

A complete C++ learning repository covering concepts from **Basic to Advanced** with practical examples and problem-solving programs.

## 📚 Topics Covered

### 📌 A — Basics of C++

* Introduction to C++
* Variables & Data Types
* Input / Output
* Operators
* Type Casting

### 📌 B — If-Else Conditions

* Simple If
* If-Else
* Nested If
* Else-If Ladder
* Switch Case

### 📌 C — Loops in C++

* For Loop
* While Loop
* Do-While Loop
* Nested Loops
* Loop Control Statements

### 📌 D — Pattern Printing

* Star Patterns
* Number Patterns
* Pyramid Patterns
* Hollow Patterns

### 📌 E — Functions

* Function Basics
* Parameters & Arguments
* Return Type
* Function Overloading
* Recursion Basics

### 📌 F — Pointers

* Pointer Basics
* Pointer Arithmetic
* Arrays & Pointers
* Dynamic Memory Allocation

### 📌 G — Recursion

* Recursive Functions
* Factorial
* Fibonacci
* Backtracking Basics

### 📌 H — Arrays

* 1D Arrays
* Array Operations
* Searching
* Sorting

### 📌 I — 2D Arrays

* Matrix Basics
* Matrix Operations
* Row & Column Problems

### 📌 J — Strings

* String Basics
* String Functions
* Character Arrays
* String Problems
